# event
イベントに関する設計ノート。

## イベントのポーリング
void nmPollEvents(void);

キューに溜まっているイベントを全て処理して即座に戻る。
ブロックしないため、定期的に呼ぶ必要がある。
内部的にはGLFWのイベント機構を使用するが、その知識は外部に漏らさない。

## イベントの待機
void nmWaitEvents(void);

少なくとも1つのイベントが届くまで呼び出しスレッドをブロックする。
イベント駆動のアプリケーションで CPU 使用率を抑えたいときに使う。
内部的にはGLFWのイベント機構を使用するが、その知識は外部に漏らさない。

## 時刻の取得
double nmGetTime(void);

`nmInitAwt` 呼び出しからの経過時間を秒で返す。単調増加（monotonic）で、システムの壁時計の変更には影響されない。
アニメーション、レート測定、デルタタイム計算などに使う。

`nmInitAwt` 前に呼んだ場合の戻り値は未定義。
内部的には GLFW のタイマーを使用するが、その知識は外部に漏らさない。
