# event
イベントループおよび時刻取得に関する設計ノート。
キューに溜まる入力イベント (キー、マウス、ウィンドウ等) の処理と、フレーム制御に必要な時刻の取得を提供する。

awt-c では「イベントループ」自体を型として持たない。
ループの駆動は呼び出し側が `nmPollEvents` / `nmWaitEvents` を周期的に呼ぶことで行う。
内部的には GLFW のイベント機構およびタイマーを使用するが、その知識は外部に漏らさない。

## イベントのポーリング
void nmPollEvents(void);

キューに溜まっているイベントを全て処理して即座に戻る。
ブロックしないため、定期的に呼ぶ必要がある。
コールバック (キー、マウス、ウィンドウのリサイズ等) はこの呼び出し中に同期的に実行される。

### 事前条件
* `nmInitAwt()` が事前に呼び出されていること。違反した場合の動作は UB。

## イベントの待機
void nmWaitEvents(void);

少なくとも 1 つのイベントが届くまで呼び出しスレッドをブロックする。
イベント駆動のアプリケーションで CPU 使用率を抑えたいときに使う。
コールバックは `nmPollEvents` と同様、この呼び出し中に同期的に実行される。

### 事前条件
* `nmInitAwt()` が事前に呼び出されていること。違反した場合の動作は UB。

## 時刻の取得
double nmGetTime(void);

`nmInitAwt` 呼び出しからの経過時間を秒で返す。
単調増加 (monotonic) で、システムの壁時計の変更には影響されない。
アニメーション、レート測定、デルタタイム計算などに使う。

### 事前条件
* `nmInitAwt()` が事前に呼び出されていること。違反した場合の戻り値は未定義。
